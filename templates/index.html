How to get your flashcards into Anki

You have 2 options — pick whichever works best for you.

Option 1 — Connect this website directly to Anki

Recommended

First-time users: follow Steps 1–7 once. After setup, you only need Step 8 whenever you use the website.

  1. Open the Anki desktop app (not AnkiWeb) → Tools → Add-ons.
  2. Click Get Add-ons... → enter 2055492159 → click OK.
  3. Wait for AnkiConnect to install, then restart Anki.
  4. Come back to this website and reload the page while Anki is open.
  5. If your browser asks for permission to allow this website to access services on your computer, choose Allow.
  6. If Anki asks whether this website may connect, choose Yes/Allow.
  7. If the connection is still blocked, see the troubleshooting message shown by the website and check AnkiConnect's webCorsOriginList.
Browser permissions: if you previously blocked local-device access or notifications, use the browser's site-settings icon next to the website address to allow the required permissions, then reload the website.
API key: if your AnkiConnect configuration requires an API key, the website will ask for it once per browser session.
Steps 1–7 are only for first-time users. You do not normally repeat them.

Step 8 — Normal use

Every time
  1. Open the Anki desktop app and keep it running.
  2. Open this website.
  3. Wait for Connected to Anki at the top.
  4. Choose single-word or topic mode, select your language and Anki deck, and create your flashcard(s).
  5. Click Add to Anki.
  6. The flashcard and available pronunciation audio will be stored in your selected deck.
Returning users: you only need to follow Step 8.
Anki must be open and running for the direct Anki features to work.

Option 2 — Download the flashcard manually

Alternative

You can download the flashcard and import it into Anki manually.

  1. Click Download Flashcard. The file will be saved to your computer's Downloads folder.
  2. Open the downloaded file in Anki.
  3. Click Import.
  4. The card will use your selected deck name when the deck name is provided.
The downloaded flashcard contains the flashcard content and available pronunciation audio.
Important: Anki must be open and running for Add to Anki and Create New Deck to work.
